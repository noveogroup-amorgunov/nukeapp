# IconButton: click area не покрывает контейнер span.root

Reporter: @amorgunov (maintainer), 2026-09-14. Outgrowth of layout-refactor regression pass.

## Problem

Клик обрабатывается только на внутреннем `button.control` (svg-контейнер
32×32). Внешний `span.root` — обёртка над кнопкой и бейджем — клики по своим
зонам (в т.ч. по бейджу с количеством) не обрабатываются.

## Proposed direction

Удалить `span.root`-обёртку вообще: рендерить `button.control` напрямую с
паддингами (как сейчас), а бейдж позиционировать относительно родителя, либо
перенести клик-обработку на контейнер. Отдельно решить судьбу asChild-режима
(Slot-мерж в Link) — клик-зона должна совпадать с визуальной.

## Repro

Навести на правый слот хедера: зона между краем span и кнопкой не реагирует;
клик по бейджу (кружок с числом) не вызывает переход по Link.
